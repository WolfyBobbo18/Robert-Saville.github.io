Capping Project – Puzzle UI & Interface Design

As part of my senior capstone project, I worked on the design and development of user interface systems that supported player exploration, puzzle solving, and overall usability throughout the game experience.

Project Overview

The goal of the project was to create an engaging puzzle-based game experience while ensuring that players could easily understand game mechanics, navigate menus, and interact with gameplay systems.

The challenge was balancing functionality with immersion. The interface needed to communicate important information without distracting players from exploration and puzzle solving.

My Role

  • UI/UX Design
  • Wireframing & Prototyping
  • Interface Layout Design
  • Usability Testing
  • Quality Assurance Testing

Design Process

I began by creating wireframes and early interface concepts in Figma. Multiple layouts were explored to determine how information could be presented clearly while maintaining a consistent visual style.

Throughout development, I iterated on designs based on team feedback and testing sessions. Adjustments were made to improve readability, navigation flow, and overall player experience.

Key Contributions

  • Designed puzzle-solving interface systems
  • Created exploration and navigation menus
  • Developed interface layouts that integrated directly into gameplay
  • Refined designs through iterative testing and feedback
  • Supported quality assurance testing throughout development

Tools Used

  • Figma
  • Unity

Outcome

The final implementation provided players with intuitive interface systems that supported gameplay without becoming intrusive. The project strengthened my experience in UI/UX design, iterative development, collaboration within a multidisciplinary team, and designing interfaces specifically for game environments.
