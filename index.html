About Me

Hi, I'm Robert Saville, a recent Cum Laude graduate from Marist University.

Capping Project – Puzzle UI & Interface Design

As part of my capstone game project, I designed and refined user interface systems that supported player exploration and puzzle solving throughout the game. My work focused on creating clear, intuitive interfaces that communicated gameplay information without distracting from the player experience. Using Figma, I iterated on multiple UI concepts, refining card layouts, exploration menus, and interaction systems based on feedback and testing. The final implementation included a puzzle solving interface integrated directly into gameplay, along with supporting menus and navigation elements that helped create a cohesive visual experience across the project.
